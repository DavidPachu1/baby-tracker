# Baby Tracker — Registro del sueño de bebés

> *Nombre provisional, en revisión.*

Aplicación móvil para que las familias registren y hagan seguimiento del descanso y el sueño de sus bebés. Proyecto propio **en desarrollo activo**, realizado en colaboración con una asesora del sueño infantil que participa como socia en la definición de producto y la validación con usuarias reales.

> ⚠️ **Repositorio de presentación:** contiene documentación y capturas del proyecto. El código fuente se mantiene privado por tratarse de un proyecto con fines comerciales.

## 🎯 Qué resuelve

Las familias que trabajan el descanso de un bebé necesitan registrar rutinas, siestas y sueño nocturno de forma sencilla para detectar patrones. Baby Tracker centraliza ese registro en una app pensada para el uso diario, con el respaldo del criterio de una profesional del sueño.

## 🛠️ Stack técnico

- **Flutter** (Dart) — app nativa para Android, orientada a publicación en Google Play.
- **Firebase**
  - Authentication — registro e inicio de sesión de las familias.
  - Cloud Firestore — base de datos de los registros de sueño.
  - Storage — almacenamiento de archivos.
- Modelado de datos y gestión de información personal con criterios de privacidad.
